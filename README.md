## 📂 Проекты в портфолио

### 1. Коллекции API‑тестов в Postman  
Набор запросов для тестирования REST‑сервиса (авторизация, CRUD, фильтрация).  
Особенности:  
- Переменные окружения (dev/stage/prod)  
- Автоматическая валидация JSON‑схем  
- Генерация отчётов через Newman + интеграция с Jenkins  
→ [Подробнее](./postman/README.md)

### 2. Перехват и модификация трафика с Charles Proxy  
Сценарии:  
- Подмена ответов для тестирования ошибочных кодов  
- Эмуляция медленного соединения (throttling)  
- Расшифровка HTTPS‑трафика, анализ заголовков  
→ [Подробнее](./charles/README.md)

### 3. Дашборды мониторинга в Grafana  
Источники: Prometheus + Elasticsearch.  
Визуализации:  
- Графики загрузки API, времени ответа, кодов HTTP  
- Алерты при превышении порогов  
- Готовые JSON‑экспорты для быстрого развёртывания  
→ [Подробнее](./grafana/README.md)

### 4. Анализ логов и визуализация в Kibana  
Настройки:  
- Сохранённые поиски по ключевым полям  
- Визуализации (гистограммы, таблицы, географические карты)  
- Дашборды для отслеживания ошибок в продакшене  
→ [Подробнее](./kibana/README.md)

### 5. BI‑отчёты в Metabase  
Примеры:  
- Дашборды с метриками качества (количество багов, покрытие тестами)  
- Вопросы (SQL‑запросы) по данным из тестовой БД  
- Автоматическая рассылка отчётов по почте  
→ [Подробнее](./metabase/README.md)

### 6. Спецификации OpenAPI (Swagger)  
Документация API, сгенерированные клиенты, примеры запросов/ответов.  
→ [Подробнее](./api-docs/README.md)
